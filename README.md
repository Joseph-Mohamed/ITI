This repository contains my tasks, exercises, notes, and practical work completed during the **ITI Summer Camp 2026 — Frontend React track**.

The repository documents my learning journey through the main technologies used in modern frontend development, starting with the fundamentals of **HTML and CSS** and progressing toward **JavaScript and React**.
