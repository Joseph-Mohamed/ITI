## 📌 About This Repository

This repository documents my comprehensive hands-on learning path, daily coding milestones, assignments, and mini-projects completed during the **Information Technology Institute (ITI) Summer Camp — Frontend (React) Track**. 

It reflects a structured transition from core web fundamentals to building dynamic, component-driven Single Page Applications (SPAs) using modern JavaScript and React.

> 🎯 **Core Objective:** Mastering modern frontend engineering practices, writing clean & scalable code, implementing responsive UI designs, and bridging robust logic with intuitive user experiences.

## 🗓️ Daily Training Roadmap & Highlights

### 🌐 Phase 1: Foundations, CSS & Layouts (Days 01 - 10)
* **`Day01` & `Day02`**: HTML syntax, semantic tags, document structures, tables, lists, and forms (refined post-solution).
* **`Day03`**: Portfolio layout design and multi-section page structuring.
* **`Day04`**: Comprehensive HTML summaries, structural organization, and accessibility standards.
* **`Day05`**: *Pizza Task (Colored)* focusing on advanced CSS styling, custom color palettes, and layout positioning.
* **`Day06` & `Day07`**: Profile Card implementations, component styling, and responsive card grids.
* **`Day08`**: Introduction to **Bootstrap 5**, grid systems, spacing utilities, and responsive design paradigms.
* **`Day10` & `Day10_Bakery`**: Multi-page/component layouts for Pizza and Bakery themed applications.

### ⚡ Phase 2: JavaScript Core & Logic (Days 11 - 15)
* **`Day11` & `Day12`**: JavaScript fundamentals, data types, control flow structures, loops, and basic DOM manipulation.
* **`Day13`**: Advanced functions, array methods, objects, string manipulation, and algorithmic logic tasks.
* **`Day14` & `Day_14`**: Asynchronous JavaScript, event handling, execution context, and callback flows.
* **`Day15`**: *Pizza App Logic Integration* tying dynamic JavaScript behavior with UI elements.

### ⚛️ Phase 3: React & Modern SPA Development (Days 16 - 18)
* **`Day16/first-react-app`**: Transitioning to React via Vite, understanding component architecture, JSX, and initial props.
* **`Day17/new_react_app`**: State management (`useState`), event handling, and data passing across parent-child components.
* **`Day18/new_react_app`**: Advanced React patterns, side-effect handling (`useEffect`), hooks, and interactive UI component states.
