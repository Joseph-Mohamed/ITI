## 📌 About This Repository

Welcome to my **ITI Web Development Using React** repository!

This repository documents my learning journey through the **144-hour
training program at the Information Technology Institute (ITI)**. It
covers the essential building blocks of front-end development, starting
with HTML and CSS, moving through JavaScript and asynchronous
programming, and finishing with React fundamentals and modern
application development.

Each phase is organized into folders so you can easily explore the
topics, exercises, and projects completed during the training.

> 💡 **My goal:** Build a strong front-end foundation and turn concepts
> into clean, responsive, and interactive web applications.
