## 🗺️ Project Roadmap & Daily Breakdown

<details>
  <summary><b>🌐 Phase 1: HTML, CSS & Layout Architectures (Days 01 - 10)</b></summary>
  <br>
  <ul>
    <li><b>Day01 & Day02:</b> HTML5 semantic elements, document structuring, forms, tables, and lists (refined post-solution).</li>
    <li><b>Day03:</b> Custom multi-section Portfolio layout design.</li>
    <li><b>Day04:</b> Comprehensive HTML summary, accessibility standards, and document best practices.</li>
    <li><b>Day05:</b> <i>Pizza Task (Colored)</i> focusing on advanced CSS styling, custom color harmony, and structural positioning.</li>
    <li><b>Day06 & Day07:</b> Responsive Profile Card layouts and reusable component styling.</li>
    <li><b>Day08:</b> Introduction to <b>Bootstrap 5</b> grid systems, spacing utilities, and responsive design paradigms.</li>
    <li><b>Day10 & Day10_Bakery:</b> Multi-page layout integration for Pizza and Bakery themed web apps.</li>
  </ul>
</details>

<details>
  <summary><b>⚡ Phase 2: JavaScript Core, ES6+ & Logic (Days 11 - 15)</b></summary>
  <br>
  <ul>
    <li><b>Day11 & Day12:</b> JavaScript fundamentals, variables, control flow, loops, scope, and DOM manipulation.</li>
    <li><b>Day13:</b> Advanced functions, ES6 array methods (map, filter, reduce), objects, and logic challenges.</li>
    <li><b>Day14 & Day_14:</b> Asynchronous JavaScript (Promises, async/await), event handling, and execution context.</li>
    <li><b>Day15:</b> <i>Pizza App Logic Integration</i> tying dynamic JavaScript behavior with UI interactions.</li>
  </ul>
</details>

<details open>
  <summary><b>⚛️ Phase 3: React & Modern SPA Development (Days 16 - 18)</b></summary>
  <br>
  <ul>
    <li><b>Day16 (`first-react-app`):</b> Transitioning to React via Vite, understanding JSX syntax, component trees, and props.</li>
    <li><b>Day17 (`new_react_app`):</b> Local state management (<code>useState</code>), event handling, and parent-child data flow.</li>
    <li><b>Day18 (`new_react_app`):</b> Advanced React patterns, side-effect handling (<code>useEffect</code>), custom hooks, and dynamic UI reactivity.</li>
  </ul>
</details>
