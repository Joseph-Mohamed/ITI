## 🔷 About This Repository

Welcome to my **ITI Summer Camp 2026 — Frontend (React)** repository!

This repository documents my learning journey through the **144-hour Web Development Using React training program at the Information Technology Institute (ITI)**.

Throughout this journey, I explored essential web technologies, practiced problem-solving, developed interactive interfaces, and worked on practical projects.

The repository is organized into three main learning phases:

- 🌐 **Web Foundations:** HTML5, CSS3, and Bootstrap.
- ⚡ **JavaScript Development:** JavaScript, ES6+, DOM Manipulation, and Asynchronous Programming.
- ⚛️ **React Development:** JSX, Components, Props, State, and React Hooks.

> 💡 **My Philosophy:** Learn the fundamentals, practice consistently, and turn ideas into real-world applications.
